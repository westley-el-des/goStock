# GoStock

## 📦 Sistema de Gestão de Estoque

O **GoStock** é um sistema de gestão de estoque desenvolvido com o objetivo de facilitar o controle de produtos, quantidades e datas de validade.

O sistema foi desenvolvido como projeto acadêmico no curso de **Sistemas de Informação**.

## 🎯 Objetivo

O principal objetivo do GoStock é auxiliar no controle de estoque, permitindo que o usuário acompanhe os produtos cadastrados e identifique situações que precisam de atenção, como:

- Produtos com estoque baixo
- Produtos próximos do vencimento
- Produtos vencidos
- Quantidade disponível em estoque

## ⚙️ Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Controle de quantidade
- Controle de data de validade
- Identificação de produtos próximos do vencimento
- Identificação de produtos vencidos
- Alertas de estoque baixo
- Sistema de autenticação de usuários
- Controle de produtos por usuário

## 🛠️ Tecnologias utilizadas

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **Bootstrap**
- **SQLite**
